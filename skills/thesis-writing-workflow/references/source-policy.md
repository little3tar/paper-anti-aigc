# 论文工作流来源策略

## 强制三级检索协议（⭐）

当论文写作需要某条信息（文献、参数、标准、数据等）时，**必须按以下顺序依次尝试三个信息源，每项都要尝试**，不得只查一项就放弃，也不得第一项有结果就跳过后续项：

| 优先级 | 信息源 | 操作 |
|---|---|---|
| **第一级** | Zotero MCP / 本地文献 MCP | 检索文献库，获取文献题名、摘要、笔记/标注（征求用户同意后） |
| **第二级** | 用户 | Zotero 未找到或信息不完整时，向用户索要材料、数据、参数值或确认 |
| **第三级** | 网络搜索 | 以上两项均未获得所需信息时，使用 Web 搜索，优先可靠来源（官方标准平台、期刊页面、厂商页面、高校文库等） |

**执行规则**：
- 每级检索后汇总该级结果，再进入下一级。即使第一级 Zotero 返回了结果，如果信息不完整（如缺少版本/年份、缺少具体参数值），仍需继续后续级别的检索。
- **只有三级都尝试过仍未获取的信息，才能列入 `证据缺口清单` 或标为 `[设计假设: ...]`。**
- 每一级的检索结果在审计报告或证据表中标注信息来源渠道（如 `[Zotero]`、`[用户提供]`、`[网络检索]`）。

标准规范同样按三级检索：先查 Zotero/本地文献 → 询问用户是否有标准文件 → 搜索官方标准平台（如 openstd.samr.gov.cn、hbba.sacinfo.org.cn）或标准发布机构官网。

此协议覆盖所有阶段的信息检索：大纲规划的文献池建立、章节写作的证据检索、审计阶段的缺来源补全、修复闭环中的替代来源查找。

## 标准收录与核验

检索到的标准规范必须落盘到 `ledger/facts.md`（标准规范引用表）：

| Marker | 标准名称 | 标准号 | 版本/年份 | 发布机构 | 适用条款 | 核验状态 | 核验平台 |
|---|---|---|---|---|---|---|---|
| [标准规范: GB/T 2348] | 液压缸缸径及活塞杆直径系列 | GB/T 2348-2018 | 2018 | SAC | 缸径/杆径第一系列 | 待核验 | — |

核验状态：`待核验` / `已核验` / `核验失败（疑似不存在）`。

**核验门**：收录前至少通过一个官方平台交叉确认标准号和版本真实存在。优先使用：
- 国家标准全文公开系统（openstd.samr.gov.cn）
- 行业标准信息服务平台（hbba.sacinfo.org.cn）
- 标准发布机构官网

`核验失败` 的标准不进入正文、不作为设计依据。`待核验` 标准可用于计算底稿但正文中保留工作标注 `[标准规范: ...]`。

## 回退行为

当 Zotero MCP 不可用时，遵循强制三级检索协议的调整版：

1. 检查是否有其他 MCP/资源暴露了本地文献（替代 Zotero 第一级）。
2. 当需要本地文献准确性时，询问用户能否提供 `.bib`、`.ris`、`.csv`、PDF 文件夹或参考文献清单（第二级）。
3. 仅在三级检索协议中的前两级已尝试但仍不足时使用网络搜索（第三级）。
4. 当本地文献不包含所需的标准号、版本、年份、发布机构或条款范围时，继续按三级协议向用户索要、然后搜索外部来源。

## 停止条件

以下情况停止并询问用户：

- 请求的输出格式影响文件创建或文档工具选择。
- 大纲改变了论文范围。
- 某章依赖不可用的实验数据、尺寸、压力/流量值或导师特定要求。
- 某章依赖用户自制材料，如图纸、测量数据、实验记录、仿真截图、程序输出、设备选型、现场照片或导师批注。
- 草稿经审计后存在 P0/P1 证据问题。

如果用户明确授权预授权连续模式，则不对输出格式和工作流产物更新暂停；在 handoff 或 project ledger 中记录假定的决策。但仍需在以下情况暂停：缺失用户自制数据、无法核验最终结论所需的标准、真实提交工作中未解决的 P0/P1 问题，以及直接修改真实论文主文件（除非该修改已被明确预授权）。

## 证据缺口处理

无支撑的事实、参数、公式、标准、性能结论和定论不得进入论文正文。将其记录在 `未写入正文的待补资料`、`证据缺口清单` 或 project ledger 中，注明需要的证据类型和可能的来源路径。仅在获得本地/Zotero 证据、用户提供材料、已确认设计假设、已核验标准/规范或可复现推导支撑后，才将其写入正文。

对于未核验的标准/规范，记录所需的标准名称、候选标准号、发布机构、年份/版本、条款范围和搜索来源。在版本和适用性得到核验之前，不得将标准作为权威依据引用。
