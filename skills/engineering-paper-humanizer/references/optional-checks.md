# 可选检查与质量评分

> 本文件包含 engineering-paper-humanizer 技能的可选检查内容，仅在用户明确要求时使用。

## 质量评分标准（可选自检）

对改写后的文本进行 1-10 分评估（总分 50）。评分目标不是“越精炼越好”，而是“核心意思不变，同时更像普通学生稿”：

| 维度       | 评估标准                                                          | 得分    |
| ---------- | ----------------------------------------------------------------- | ------- |
| **保真度** | 原文核心意思、参数、单位和结论方向是否保住？（10分：完全保住；1分：意思变了） | /10     |
| **普通度** | 是否像普通学生按资料写出来？（10分：平实普通；1分：专业精修稿） | /10     |
| **松散度** | 是否避免过度精炼、过度压缩？（10分：有适当“的、了、这个、这样”；1分：技术摘要感很强） | /10     |
| **结构变化** | 是否调整了语序、主谓宾和句式骨架？（10分：骨架明显变了；1分：只换同义词） | /10     |
| **检测风险** | 是否减少模板句、漂亮结尾、机械枚举和说明书口吻？（10分：明显减少；1分：基本没变） | /10     |
| **总分**   |                                                                   | **/50** |

**评分标准：**

- 45-50 分：较好，基本达到“意思不变但更像普通学生稿”的状态
- 35-44 分：可用，但仍有一些过于精炼或模板化的地方
- 低于 35 分：需要重新修订，通常是句式骨架变化不够或仍像模型总结

## 使用说明

当用户明确要求评估机械化程度、模板化程度或进行质量评分时，按此标准执行评估。评估结果可作为改写质量的参考，但不影响核心改写流程。
