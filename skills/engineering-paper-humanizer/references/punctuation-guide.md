# 中文工程论文标点专项规则

本文件只处理正文中的通用中文标点问题。LaTeX 命令、Markdown 代码块、引用位置和文件格式问题交给 `academic-format-cleaner`。

## 引号

### 使用层级

- 中文正文引用、特指术语、非正式称谓：`“...”`
- 引号内部再引用：`‘...’`
- 书名、论文名、标准名、法规名：`《...》`
- 代码、命令、变量、路径、文件名：反引号或等宽命令，不用中文引号
- 英文整句引用：保留英文排版习惯；LaTeX 中优先用 TeX 式引号或 `\enquote{}`

### 常见错误

- ASCII 直双引号：`"..."` 出现在中文正文中。
- 中英文半边混用：`“..."`、`"... ”`。
- 只为了强调而加引号：`“显著提升”`、`“创新性”`。
- 书名、标准名误用双引号。

### 改写判断

如果引号里的词只是强调词，直接删除引号。  
如果是术语首次出现，保留中文引号或改为定义句。  
如果是文献、标准、法规名称，优先改书名号。  
如果是代码或路径，改为反引号或等宽命令。

## 破折号和 dash

### 默认策略

中文学术正文中默认删除破折号。AI 文本常用破折号制造“解释”“转折”“金句”效果，工程论文通常不需要这种语气。

### 处理方式

- 解释关系：改为“即”“也就是说”，或直接拆成两句。
- 补充插入：改为逗号、分号或拆句，不再优先使用括号。
- 强转折：改为分号或句号。
- 标题副题：可保留，但优先考虑冒号。

### 例外

以下场景不按破折号滥用处理：

- 数字范围：`20–50 Hz`、`12--15 页`
- 数学负号或区间
- 复合术语：`3-RPS`、`PID-模糊复合控制`
- 代码、命令、路径、文件名
- Markdown frontmatter 或表格分隔符

## 二次检查

改完标点后再读一遍前后句。若删除破折号后句子变得生硬，不要机械替换成逗号；应根据语义拆句或补一个自然连接词。

## 括号

### 默认策略

中文正文中的解释性括号默认清理。括号会让段落像教材、百科或 AI 生成的补充说明，尤其是“即……”“例如……”“检查……”“说明……”这类括号。

### 只保留这些括号

- 专业缩写或英文全称：`振荡截割盘（Oscillating Disc Cutting, ODC）`
- 标准号、型号、规范编号：`GB/T 20721-2022`
- 必要参数、单位或公式口径：`31.5 MPa`、`UCS = 160 MPa`
- 不适合拆开的外文名、变量名或代号

### 处理方式

- 中文解释括号能并入正文就并入正文：`空载升降（检查同步性）` → `空载升降主要检查同步性`
- 不影响核心意思的括号直接删掉。
- 不要把破折号删掉后再用括号承接，否则只是把一个 AI 痕迹换成另一个。

### 标准引用括号专项处理

工程论文正文中反复出现"按 GB/T XXXX 取"、"（GB/T XXXX-XXXX）"、"依据 MT/T XXXX"等标准引用。AI 倾向于把这些标准号整齐地嵌在括号里或放在"按……取"的固定模板中，形成高重复度的机械节奏。检测器会把这些整齐的引用链标记为模板化痕迹。

#### 识别模式

| 模式 | 示例 | AI 痕迹原因 |
|---|---|---|
| 括号尾注 | `杆径取 d=70 mm（GB/T 2348-2018 第一系列）` | 全章重复十几次，节奏整齐 |
| 前置模板 | `按GB/T 2348-2018第一系列优先值，向上圆整取 D=100 mm` | "按……取"骨架全章不变 |
| 堆叠引用 | `符合 GB/T 2346-2003、GB/T 2348-2018 和 GB/T 2349-1980 的规定` | 标准号三连排比 |

#### 改写策略

**括号尾注 → 化入正文承接**：

```
❌ 杆径取 d=70 mm（GB/T 2348-2018 第一系列）
✅ 杆径 d 取 70 mm，这也是 GB/T 2348-2018 第一系列里的优先值
```

如果同一标准在同节内反复出现，后续可以只说"对照第一系列的优先值"，不必每次都重复完整标准号。

**前置模板 → 变换承接词**：

```
❌ 按GB/T 2348-2018第一系列优先值，向上圆整取 D=100 mm
✅ 对照GB/T 2348-2018第一系列的优先值，往大了取，D 取 100 mm
```

关键不是删标准号，而是打破"按……取"的固定骨架。可以轮换使用"对照……""参照……""按……来选""依据……"等不同说法，且不要把"向上圆整""优先值"这些词每次都原样带上。

**堆叠引用 → 拆散**：

```
❌ 符合 GB/T 2346-2003、GB/T 2348-2018 和 GB/T 2349-1980 的规定
✅ 压力等级按 GB/T 2346-2003 来定，缸径和杆径对照 GB/T 2348-2018 第一系列，行程参照 GB/T 2349-1980
```

**允许保留的情况**：

- 表格内的参数列：`D / mm（GB/T 2348-2018）` 作为表头标注，可保留括号
- 首次出现的标准全称：`根据GB/T 2346-2003《流体传动系统及元件 公称压力系列》` 可保留
- 公式参数说明中的简写：`P 为公称压力（GB/T 2346-2003）` 可保留

#### 与普通解释性括号的区别

普通解释性括号是语义层面多余（"截割臂（含截割盘、激振机构、臂架结构）"），标准引用括号是语义必要但表达生硬。前者直接清理，后者保留标准号但改写承接方式。

#### 检查清单

润色完成后逐条检查：
1. 全章"按 GB/T……取"出现了多少次？超过 5 次就必须变化承接词
2. "（GB/T XXXX-XXXX）"括号尾注是否有 5 处以上？超过就必须改掉大部分
3. 有没有连续两句话使用完全相同的引用句式？如果有，必须改写其中一句
