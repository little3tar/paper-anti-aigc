# 中文工程论文标点专项规则

本文件只处理正文中的通用中文标点问题。LaTeX 命令、Markdown 代码块、引用位置和文件格式问题交给 `academic-format-cleaner`。

## 引号

### 使用层级

- 中文正文引用、特指术语、非正式称谓：`“...”`
- 引号内部再引用：`‘...’`
- 书名、论文名、标准名、法规名：`《...》`
- 代码、命令、变量、路径、文件名：反引号或等宽命令，不用中文引号
- 英文整句引用：保留英文排版习惯；LaTeX 中优先用 TeX 式引号或 `\enquote{}`

### 常见错误

- ASCII 直双引号：`"..."` 出现在中文正文中。
- 中英文半边混用：`“..."`、`"... ”`。
- 只为了强调而加引号：`“显著提升”`、`“创新性”`。
- 书名、标准名误用双引号。

### 改写判断

如果引号里的词只是强调词，直接删除引号。  
如果是术语首次出现，保留中文引号或改为定义句。  
如果是文献、标准、法规名称，优先改书名号。  
如果是代码或路径，改为反引号或等宽命令。

## 破折号和 dash

### 默认策略

中文学术正文中默认删除破折号。AI 文本常用破折号制造“解释”“转折”“金句”效果，工程论文通常不需要这种语气。

### 处理方式

- 解释关系：改为“即”“也就是说”，或直接拆成两句。
- 补充插入：改为逗号、分号或拆句，不再优先使用括号。
- 强转折：改为分号或句号。
- 标题副题：可保留，但优先考虑冒号。

### 例外

以下场景不按破折号滥用处理：

- 数字范围：`20–50 Hz`、`12--15 页`
- 数学负号或区间
- 复合术语：`3-RPS`、`PID-模糊复合控制`
- 代码、命令、路径、文件名
- Markdown frontmatter 或表格分隔符

## 二次检查

改完标点后再读一遍前后句。若删除破折号后句子变得生硬，不要机械替换成逗号；应根据语义拆句或补一个自然连接词。

## 括号

### 允许保留的括号

以下两类括号在润色后可保留：

- 专业缩写或英文全称：`振荡截割盘（Oscillating Disc Cutting, ODC）`、`可编程逻辑控制器（Programmable Logic Controller, PLC）`
- 不适合拆开的外文名、变量名或代号

### 需清理的括号及处理方式

中文正文中的解释性括号默认清理。括号会让段落像教材、百科或 AI 生成的补充说明，尤其是”即……””例如……””检查……””说明……”这类括号。

以下类型的括号**全部通过语言叙述替代**，不得保留括号形式：

- 参数说明数值：`超过25MPa的1.1倍（约27.5MPa）` → `超过25MPa的1.1倍，也就是约27.5MPa`
- 量程/单位：`压力传感器（4~20mA，量程0~400bar）` → `压力传感器，输出4~20mA、量程0~400bar`
- 标准号引用：`杆径取 d=70 mm（GB/T 2348-2018 第一系列）` → `杆径 d 取 70 mm，对照 GB/T 2348-2018 第一系列`，或直接写标准全称
- 条件补充：`启动加热器（如果配备）` → `如果配了加热器就启动`
- 中文解释括号能并入正文就并入正文
- 不影响核心意思的括号直接删掉
- 不要把破折号删掉后再用括号承接
