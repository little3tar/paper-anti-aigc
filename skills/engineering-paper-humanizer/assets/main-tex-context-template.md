# main-tex-context.md 模板

更新或重置 `main-tex-context.md` 时，按以下结构填充。模板适用于 Markdown、LaTeX、plain text 等格式，公式和参数统一使用 LaTeX math。

```markdown
# 论文主文件结构地图

项目：《论文标题》
主文件路径：`<由用户确认，如 thesis.md / main.tex / 论文.txt>`
目标输出格式：Markdown / LaTeX / plain text → docx（pandoc 转换）
论文模板来源：学校模板 / 自建 / 无

## 第 N 章：章节标题

- **核心对象**：...
- **核心痛点/发现**：...
- **关键参数**：...

（按主文件实际章节逐章列出，每章提取 2-5 个关键事实）

## 引用方案

- 引用标记格式：`[文献题名]` / `[参考文献]` / `\cite{...}`
- 参考文献管理：Zotero / `.bib` 文件 / 手动
- 最终引用样式：编号引用 `[1]` / 作者-年份 / 脚注

## 排版约定

- 正文语言：中文
- 标题编号：是 / 否
- 图表编号：按章编号（图 2-1）/ 连续编号 / 其他
- 段落风格：首行缩进 / 段间空行

## 可直接复用的核心参数

| 参数 | 值 | 来源 |
| ---- | -- | ---- |
| ...  | .. | ...  |

## 公式约定

- 行内公式：`$...$`
- 块级公式：`$$...$$` 或 `\[...\]`
- 公式编号：按章编号 / 连续编号 / 不编号
```
